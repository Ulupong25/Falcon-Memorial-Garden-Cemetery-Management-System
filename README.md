# Falcon Memorial Garden Cemetery Management System
## Description
A professional management system designed to streamline cemetery records and memorial garden logistics.
## Tech Stack
* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
## Installation Guide
1. Clone the repository.
2. Import the SQL file into PHPMyAdmin.
3. Run via XAMPP.
